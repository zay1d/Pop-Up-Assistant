# Pop-Up — учёт размещений в ТЦ

## Как открыть
Дважды кликните **`index.html`** — приложение откроется в браузере. Установка не нужна, работает офлайн.

> Все данные хранятся внутри приложения на этом компьютере (технология IndexedDB).
> Фото и документы тоже сохраняются внутрь — отдельные файлы носить не нужно.

## Экраны
- **Главная** — крупные кнопки и сводка: сколько зон, занято/свободно сейчас.
- **Календарь** — занятость всех зон по дням. Кнопками переключаются **месяц** и **год**.
  - Нажмите на свободный день — добавить размещение.
  - Нажмите на цветную полосу — открыть карточку арендатора.
  - Стрелки ‹ › на полосе = размещение продолжается в соседнем месяце/году.
- **Карта** — план этажа. Внизу список «Поставить на карту»: нажмите зону → нажмите место на плане.
  Точки: 🟢 свободно сейчас, 🔴 занято. Клик по точке — история зоны.
- **Арендаторы** — все pop-up карточками, с поиском. Клик — полная карточка с фото, файлами и историей.
- **Отчёты** — за выбранный период: заработок (аренда), загрузка каждой площадки, список размещений.

## Карточка размещения (всё из ТЗ)
Бренд, период, контактное лицо, телефон, e-mail, фото, размеры конструкции, площадь,
подрядчик, стоимость изготовления, стоимость аренды, комментарии, статус договора,
ссылка на документы + прикреплённые файлы. Внизу — история бренда и история зоны.

## Сохранение и перенос (кнопка «⤓ Бэкап»)
- **Скачать копию** — сохраняет всё в один файл `popup-backup-….json` (бэкап).
- **Загрузить копию** — восстановить данные или перенести на другой компьютер.
- Здесь же — валюта для отчётов (по умолчанию «сум»).

## Что поправлено в списке зон (орфография)
«остравок» → «островок», «Терасса» → «Терраса», «Pаrfum» → «Parfum».
Зона «Центральный атриум (LIU·JO)» — уточните точное название бренда.
Терраса (4 этаж) пока без плана — добавим, когда будет файл плана.
